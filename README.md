## About

This lab focuses on creating an **aviation mini-campaign using Canva Magic Studio** while maintaining visual consistency, accuracy and responsible AI use.

## Tools Used

* Canva Magic Media
* Magic Expand
* Magic Edit
* Canva Resize/Adaptation Tools
* Text and Layout Tools

## Campaigns Covered

* **Travel Smart at the Airport**
* **Click Smart Before You Fly**

## Topics Covered

* Campaign brief and brand guide
* AI image generation and editing
* Social-media post, poster and presentation visual
* Brand consistency
* Image accuracy and privacy checks
* Responsible AI use
* Peer review and design refinement

## Key Learning

AI-assisted design can help create professional aviation campaigns, but every visual must be checked for **accuracy, branding, privacy, misleading information and ethical use**.

**Main Principle:**
**Create → Edit → Check Accuracy → Maintain Brand Consistency → Human Review**
